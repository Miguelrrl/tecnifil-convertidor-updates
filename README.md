# Tecnifil Convertidor para Windows

Arrastre el Excel de Administración 1, 2 o 3 y guarde su Registro de Vendedores. La aplicación portátil para Windows x64 funciona sin conexión.

- [Descargar el ejecutable](https://github.com/Miguelrrl/tecnifil-convertidor-updates/releases/latest/download/Tecnifil-Convertidor-Windows-x64.exe)
- [Consultar la guía de instalación y uso](https://github.com/Miguelrrl/tecnifil-convertidor-updates/releases/latest/download/Instrucciones-Tecnifil-Windows.pdf)
- [Ver versiones y huellas SHA-256](https://github.com/Miguelrrl/tecnifil-convertidor-updates/releases)

La versión 1.0.0 se distribuye sin firma digital. La guía explica cómo verificar el archivo si aparece un aviso de SmartScreen.
